# Call note template

One note per meaningful call, with a **subject** (the note's title field in the CRM) and a structured body. Telegraphic, factual style, **written in French** (the CRM and the team work in French). Use « non abordé » (not discussed) when a topic was not raised: never invent anything.

The French labels below must be used as they are.

## Subject

`Call <type> – <summary in a few words>`

Examples:
- `Call qualif – Délégué OTC, ouvert, dispo 3 mois`
- `Call client – 2 postes AQ ouverts, RDV fixé le 02/12`
- `Voice mail sent`

## Body — candidate

```
Contexte : <who called whom, why: direct approach, ad response, follow-up…>
Poste actuel : <title, employer, time in role, scope / sector / products>
Parcours clé : <2-3 useful points from the career>
Motivation / raison du changement : <…>
Recherche : <type of job, sector, contract sought>
Salaire : actuel <…> / souhaité <…>
Disponibilité / préavis : <…>
Mobilité : <cities / regions accepted, remote work>
Process en cours : <other interviews, offers>
Ressenti recruteur : <strengths, points of attention>
Prochaine étape : <action + date: send CV, present to client X, call back on …>
```

Label meanings: Contexte = context; Poste actuel = current job; Parcours clé = key background; Motivation / raison du changement = motivation / reason for change; Recherche = what they are looking for; Salaire actuel / souhaité = current / expected salary; Disponibilité / préavis = availability / notice; Mobilité = mobility; Process en cours = ongoing processes; Ressenti recruteur = recruiter's impression; Prochaine étape = next step.

## Body — client contact / prospect

```
Contexte : <prospecting, follow-up, inbound need…>
Interlocuteur : <role, hiring scope>
Besoins : <positions, number, location, contract, urgency>
Situation recrutement : <agencies in place, internal process, budget>
Objections / points clés : <…>
Prochaine étape : <meeting, sending terms, sending profiles, follow-up on …>
```

Label meanings: Interlocuteur = contact person; Besoins = needs; Situation recrutement = hiring situation; Objections / points clés = objections / key points.

## Body — voicemail

Subject: `Voice mail sent`

```
Appel le <date> à <heure> – répondeur, message vocal laissé.
Mail de suivi préparé dans les brouillons Outlook (<adresse e-mail>).
```

With no email on the record, replace the second line with `Pas d'e-mail sur la fiche – pas de mail de suivi.`

## Example (anonymised)

**Subject:** `Call qualif – Délégué pharma OTC, Live Speculative`

```
Contexte : approche directe via LinkedIn.
Poste actuel : Délégué pharmaceutique officine chez un labo OTC, 6 ans, secteur Gironde/Landes.
Parcours clé : 2 ans délégué en nutraceutique avant ; diplôme Visiteur médical.
Motivation / raison du changement : secteur trop étendu, souhaite moins de route.
Recherche : délégué officine ou KAM régional, CDI.
Salaire : actuel 42 k€ + variable 6 k€ / souhaité 48 k€ fixe.
Disponibilité / préavis : 3 mois.
Mobilité : Bordeaux métropole uniquement.
Process en cours : aucun.
Ressenti recruteur : très bon relationnel, chiffres solides (top 3 national 2025).
Prochaine étape : envoi CV à jour demain ; rappel le 01/12.
```

Matching coding: Markets *Sales & BD* · Industries *Pharmaceutical, Nutraceutical* · Specialisms *OTC & Consumer Health* · Skills *SREP, CRM, Field* · Seniority *Specialist/experienced* · Status *Live Speculative* · Employment *Live* · Certifications *Visiteur medical* · Target location *Bordeaux* · Contract type *Permanent*.
