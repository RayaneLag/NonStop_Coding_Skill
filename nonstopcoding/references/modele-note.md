# Modèle de note d'appel

Une note par appel significatif, avec un **sujet** (champ titre de la note dans le CRM) et un corps structuré. Style télégraphique, factuel, en français. « Non abordé » quand l'info n'a pas été évoquée : n'invente rien.

## Sujet

`Call <type> – <résumé en quelques mots>`

Exemples :
- `Call qualif – Délégué OTC, ouvert, dispo 3 mois`
- `Call client – 2 postes AQ ouverts, RDV fixé le 02/12`
- `Message vocal envoyé`

## Corps — candidat

```
Contexte : <qui a appelé qui, pourquoi : approche directe, réponse annonce, relance…>
Poste actuel : <intitulé, employeur, ancienneté, périmètre / secteur / produits>
Parcours clé : <2-3 éléments utiles du parcours>
Motivation / raison du changement : <…>
Recherche : <type de poste, secteur, contrat visé>
Salaire : actuel <…> / souhaité <…>
Disponibilité / préavis : <…>
Mobilité : <villes / régions acceptées, télétravail>
Process en cours : <autres entretiens, offres>
Ressenti recruteur : <points forts, points de vigilance>
Prochaine étape : <action + date : envoi CV, présentation au client X, rappel le …>
```

## Corps — contact client / prospect

```
Contexte : <prospection, suivi, besoin entrant…>
Interlocuteur : <rôle, périmètre de recrutement>
Besoins : <postes, nombre, localisation, contrat, urgence>
Situation recrutement : <cabinets en place, process interne, budget>
Objections / points clés : <…>
Prochaine étape : <RDV, envoi de conditions, envoi de profils, relance le …>
```

## Corps — répondeur

Sujet : `Message vocal envoyé`

```
Appel le <date> à <heure> – répondeur, message vocal laissé.
Mail de suivi préparé dans les brouillons Outlook (<adresse e-mail>).
```

Sans e-mail sur la fiche : remplacer la 2e ligne par `Pas d'e-mail sur la fiche – pas de mail de suivi.`

## Exemple (anonymisé)

**Sujet :** `Call qualif – Délégué pharma OTC, Live Speculative`

```
Contexte : approche directe via LinkedIn.
Poste actuel : Délégué pharmaceutique officine chez un labo OTC, 6 ans, secteur Gironde/Landes.
Parcours clé : 2 ans délégué en nutraceutique avant ; diplôme Visiteur médical.
Motivation / raison du changement : secteur trop étendu, souhaite moins de route.
Recherche : délégué officine ou KAM régional, CDI.
Salaire : actuel 42 k€ + variable 6 k€ / souhaité 48 k€ fixe.
Disponibilité / préavis : 3 mois.
Mobilité : Bordeaux métropole uniquement.
Process en cours : aucun.
Ressenti recruteur : très bon relationnel, chiffres solides (top 3 national 2025).
Prochaine étape : envoi CV à jour demain ; rappel le 01/12.
```

Coding correspondant : Markets *Sales & BD* · Industries *Pharmaceutical, Nutraceutical* · Specialisms *OTC & Consumer Health* · Skills *SREP, CRM, Field* · Seniority *Specialist/experienced* · Status *Live Speculative* · Employment *Live* · Certifications *Visiteur medical* · Target location *Bordeaux* · Contract type *Permanent*.
